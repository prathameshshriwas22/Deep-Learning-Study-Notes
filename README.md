# 🚀 2️⃣ ANN Fashion Image Classifier

As part of my Deep Learning practice, I built an **ANN-based Fashion Image Classification application** using TensorFlow/Keras and Streamlit.

The application allows users to upload an image and receive a predicted fashion category along with probability analysis.

### 🎯 Supported Classes

The model predicts among 10 classes:

1. T-shirt/Top
2. Trouser
3. Pullover
4. Dress
5. Coat
6. Sandal
7. Shirt
8. Sneaker
9. Bag
10. Ankle Boot
